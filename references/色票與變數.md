# 色票與 CSS 變數（權威版）

> 直接整段複製進新專案的 `:root`。**不要自己調色**——要新顏色先問南瓜。

## 完整 CSS 變數區塊

```css
:root{
  /* ── 綠系：主角 ───────────────────────── */
  --ink-forest:  #2D4321;   /* 深森林綠：主色、標題、主按鈕、深面板 */
  --ink-deep:    #1D3314;   /* 極深墨綠：黑板風面板、最深凹陷 */
  --ink-panel:   #1C3D20;   /* 面板綠：資訊面板底（比主色微亮） */
  --ink-line:    #10240F;   /* 墨線色：所有深色描邊 */
  --matcha:      #81BD49;   /* 抹茶亮綠：次標題、生機、成功 */
  --matcha-deep: #62B149;   /* 抹茶深綠：主要動作按鈕 */
  --moss:        #898B63;   /* 苔草綠：靜態標籤底、次要資訊 */

  /* ── 大地棕系：配角 ───────────────────── */
  --clay:  #D4A373;   /* 陶土棕：木質高光、強調區塊 */
  --ochre: #B99A6B;   /* 赭石棕：木質家具、邊框、獎勵 */
  --bark:  #4A3B18;   /* 深木棕：棕底上的文字 */

  /* ── 紙白系：舞台 ─────────────────────── */
  --paper:      #FCF9F0;   /* 紙白：主背景（老紙／畫布） */
  --paper-warm: #F7F1DC;   /* 奶油白：卡片、膠囊按鈕 */
  --linen:      #F4F1E8;   /* 亞麻米白：中性面板 */
  --wheat:      #E8D9B5;   /* 麥稈黃：次要按鈕、卡片底 */
  --ash:        #DDDAD1;   /* 暖灰：分隔線、未啟用、次要面板 */

  /* ── 點綴：少量 ───────────────────────── */
  --gold:   #F2C94C;   /* 金黃：選取態、皇冠、獎勵（一頁一處） */
  --alert:  #C8483A;   /* 磚紅：警示（一頁最多一處） */
  --sky-hi: #8FC7D4;   /* 天空亮：場景漸層上緣 */
  --sky-lo: #C7DDD0;   /* 天空淡：場景漸層下緣 */

  /* ── 文字 ─────────────────────────────── */
  --text:      #2A2418;   /* 主文字（暖黑，不是純黑） */
  --text-soft: #5C5334;   /* 次要文字 */
  --text-on-dark: #FDFCE3; /* 深底上的文字（米白，不是純白） */

  /* ── 形狀與光影 ───────────────────────── */
  --r-sm: 8px;    --r-md: 14px;   --r-lg: 22px;
  --bd: 3px solid var(--ink-line);
  --shadow:      0 4px 0 rgba(30,50,25,.35);   /* 硬邊等距投影 */
  --shadow-sm:   0 3px 0 rgba(40,60,30,.25);
  --shadow-in:   inset 0 2px 0 rgba(255,255,255,.08); /* 深面板頂部微光 */
}
```


## 三種底色情境的搭配

| 情境 | 底 | 文字 | 描邊 | 說明 |
|---|---|---|---|---|
| **明亮卡片** | `--paper-warm` | `--text` | `#2E2A1F` 3px | 最常用；奶油底＋深墨線 |
| **深綠面板** | `--ink-panel` | `--text-on-dark` | `--ink-line` 3px | 資訊密度高的區塊；配 `--shadow-in` |
| **黑板區塊** | `--ink-deep` | `#F2EFA8` | `#2C4A22` 2px | 日誌／活動列，像掛在牆上的黑板 |

## 狀態色語意（別亂配）

| 狀態 | 色 | 呈現 |
|---|---|---|
| 進行中／成功 | `--matcha` / `--matcha-deep` | 實心圓點、進度條填色 |
| 等待／注意 | `--gold` | 圓點＋**閃爍動畫**（1.6s） |
| 待命／停用 | `#9AA38B` 灰綠 | 實心圓點、無動畫 |
| 警示／錯誤 | `--alert` | 只用在紅點徽章或警示條 |
| 選取中 | `--gold` 外框 | `outline: 2.5px solid` ＋金色 drop-shadow 光暈 |

## 漸層唯一合法用途

**只有場景天空可以用漸層**，介面元件一律實色：

```css
background: linear-gradient(#97CCD1, #B5D8D0 60%, #C7DDD0);
```

## 紙張顆粒（大面積必加）

```html
<div id="grain"></div>
```
```css
#grain{
  position:absolute; inset:0; pointer-events:none; opacity:.35; z-index:90;
  background-image:url("data:image/svg+xml;utf8,<svg xmlns='http://www.w3.org/2000/svg' width='140' height='140'><filter id='n'><feTurbulence type='fractalNoise' baseFrequency='0.9' numOctaves='2'/><feColorMatrix type='matrix' values='0 0 0 0 0.5 0 0 0 0 0.47 0 0 0 0 0.4 0 0 0 0.05 0'/></filter><rect width='140' height='140' filter='url(%23n)'/></svg>");
}
```
內嵌 data URI＝**零外部資源**，符合單檔離線鐵則。

## 取色紀律

要從既有素材取色時，用 PIL 吸管，不要目測：

```python
from PIL import Image
im = Image.open("素材.png").convert("RGB")
r,g,b = im.getpixel((x, y)); print(f"#{r:02X}{g:02X}{b:02X}")
```
取到的色若與本表相差 5% 以內 → **用本表的值**（維持全系統一致），差很多才是新色，回報南瓜。
