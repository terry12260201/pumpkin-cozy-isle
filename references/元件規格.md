# 元件規格（可直接複製的 CSS）

> 所有元件共用：粗墨線描邊 ＋ 硬邊投影 ＋ 圓角。**按下去要像按實體積木。**

## 按鈕

```css
/* 主要動作：抹茶綠 */
.btn-primary{
  height:46px; padding:0 22px; border-radius:12px;
  background:var(--matcha-deep); color:#0E2408;
  border:3px solid var(--ink-line); box-shadow:0 3px 0 rgba(10,25,8,.5);
  font-size:17px; font-weight:800; font-family:inherit; cursor:pointer;
}
/* 次要動作：奶油底 */
.btn-secondary{
  height:46px; padding:0 22px; border-radius:12px;
  background:var(--paper-warm); color:#233018;
  border:3px solid #2E2A1F; box-shadow:0 3px 0 rgba(40,60,30,.25);
  font-size:17px; font-weight:800; font-family:inherit; cursor:pointer;
}
/* 共用互動 */
.btn-primary:hover, .btn-secondary:hover{ transform:translateY(-2px); }
.btn-primary:active, .btn-secondary:active{ transform:translateY(2px); box-shadow:none; }
```

**膠囊按鈕**（大型指令鈕）：`border-radius:28px`、字級 22px、`letter-spacing:6px; text-indent:6px`（中文才勻稱）。

**方形圖示鈕**（工具列）：`72×72px`、`border-radius:18px`、深綠底＋`--shadow-in`、內含 38–40px SVG。

## 響應式：固定舞台 ＋ 等比縮放

遊戲感介面**不要用 responsive 重排**，用固定座標舞台再整體縮放，版面永遠不會跑掉：

```js
function fit(){
  const s = Math.min(innerWidth/1672, innerHeight/941);
  stage.style.transform = `translate(-50%,-50%) scale(${s})`;
}
addEventListener("resize", fit); fit();
```
```css
#stage{ position:absolute; left:50%; top:50%; width:1672px; height:941px;
        transform-origin:center center; }
```

## 字級速查（硬底線）

| 用途 | 字級 | 字重 |
|---|---|---|
| 大數字 | ≥20px（建議 27–30） | 800 |
| 面板／區塊標題 | ≥18px | 800 |
| 主要名稱 | 20–28px | 800 |
| 內文 | ≥13px（建議 16–17） | 600–700 |
| 副標／說明 | 15–17px | 700 |
| 小標籤 | ≥11px（建議 14–16） | 700 |

**驗收方式**：1280 寬全頁截圖，肉眼逐字讀一次。讀不出來就是不合格，不接受「放大就看得到」。
